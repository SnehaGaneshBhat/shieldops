# P1 Dependency Scanner Evidence

Recorded outputs from the dependency scanner sample demonstrations.

- vulnerable_scan.json: OSV vulnerability detection using the local cache.
- suspicious_scan.json: simulated typosquatting, install-script, and new/thin-package indicators. The install script is inspected as text and never executed.
- clean_scan.json: clean local dependency sample.
- env/versions.txt: tool and library versions.

NO_KNOWN_ISSUES means no known issues were detected by the checks performed; it does not guarantee that dependencies are safe.
